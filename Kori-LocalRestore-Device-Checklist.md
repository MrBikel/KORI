# Kori Local Restore Device Checklist

Before attempting a restore, verify the following conditions to ensure data integrity and system stability.

## 1. Source Verification
- [ ] Is the backup code or file from a trusted source?
- [ ] Does the backup match the expected version (v1)?

## 2. System Integrity
- [ ] Is the device's battery sufficient to complete the restore?
- [ ] Has the current data been backed up before overwriting?

## 3. Restore Process
- [ ] Ensure the app is in the "Restore" state via the More Screen.
- [ ] Paste the backup code carefully, avoiding truncations.
- [ ] Verify the SHA-256 hash checksum in the preview matches the imported data.
